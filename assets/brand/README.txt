HOPBAG LOGO KIT
================

logo/   Lockups as outlined SVG (no fonts needed).
        horizontal / stacked / wordmark-only
        onlight = teal tile with white bag, for light backgrounds
        ondark  = tile-less bag with off-white lettering, for dark backgrounds
        mono-black / mono-white = one-colour versions (the hop arc and dots are cut out, no masks)
icon/   App icon masters and marks.
        hopbag-icon-ios-master.svg      square, 1024 px master (the OS rounds the corners)
        hopbag-android-foreground/background.svg   adaptive icon layers, 432 px (108 dp at xxxhdpi)
        hopbag-android-monochrome.svg   themed icon layer for Android 13+
        hopbag-icon-small-cut.svg       use at 32 to 48 px
        hopbag-icon-tiny-cut.svg        use at 16 to 24 px
        favicon.ico                     16, 32 and 48 px, each using its own cut
        png/                            PNG exports (64 and up use the large cut)
social/ hopbag-avatar-400.png

COLOURS
  Deep Teal  #0E3B43  rgb 14 59 67
  Orange     #F28E2B  rgb 242 142 43
  Off-white  #F7F9F9  rgb 247 249 249
  Orange is for shapes, not text on light backgrounds (low contrast).

TYPE
  Wordmark: Outfit SemiBold (600), lowercase "hopbag", tracking -2%, converted to outlines.
  Outfit is licensed under the SIL Open Font License 1.1 and is free for commercial use.

RULES
  Clear space: half the icon's height on every side.
  Minimum size: icon 24 px tall in the horizontal lockup, 32 px in the stacked lockup; below that use the icon alone.
  Do not stretch, recolour, or place the white-bag icon on a white background.

Run a trademark search on the name and mark before launch.
